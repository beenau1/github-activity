
# Contribution Guidelines

Follow these steps:

1. Fork this repository.
2. Clone your fork.
3. Create a branch named `add/your-name`.
4. Create a folder with your name.
5. Add a `README.md` inside your folder.
6. Write a short introduction about yourself.
7. Commit and push your changes.
8. Raise a Pull Request to the original repository.

## Example

your-name/README.md

## Rules

- Add only your own folder.
- Do not modify other people's files.
- Do not commit directly to `main`.
